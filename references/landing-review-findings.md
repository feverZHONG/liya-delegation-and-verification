# 把审读条目落地成修订（逐节执行协议）

> 适用：手上已有一份**核过引文**的条目清单（自己的＋委派回来的），要真的动稿。
> 分工：条目怎么写、怎么核 → 本 skill §三／§六；**本文只管「落地」这一段**。

## 一、先出计划（用户会直接要求「记得做计划」）

计划书只要五块，落盘而不是只在脑子里：

1. **口径**——只动哪一层（如只落「可直接改」的，待拍的一律不碰）；怎么定位；要不要留快照；机械项与措辞项分不分开做。
2. **分发总表**——见 §二。
3. **阶段与产出**——分发（分发表）→ 小样（一节＋账）→ 逐节（每节一账）→ 全篇复检（三件套＋同步核＋重出下游产物）→ 登记（修订账入档＋提交推送）。
4. **验收**——见 §五。
5. **卡点**——待拍项并行、行号漂移、拆分与并段（**段＝一拍；「一句就是一行」被禁，长短句同理**）、定调级条目不被本次修订绑住。

## 二、分发总表（按剧情点挂条目）

| 节 | 行范围 | 待改条目（来源·行号·病 → 改法） |
|:--|:--|:---|
| 上-1 | `文件` 1–153 | ① 来源A·L83 同一规则一节讲两遍 → 删复述尾；② 来源B·L21／25／51／127 一行挤两个说话人 → **补归属语**（「X 说／X 问」），**不拆行**——「一句就是一行」是被禁的，长短句同理 |

- 节边界＝稿子里的分隔线（`---`），**行范围按当前版本量**（改完会飘，只作参考）。
- **机械项不逐条登记**（标点连用、内引号混用、一行两说话人这类）：写一句「改完 `grep` 核零残留」比列 16 行便宜。
- 分表时要看见**节重**：哪节 5 条、哪节 0 条——节重决定改稿顺序和停点。

## 三、小样 → 逐节

- **小样＝一节（2–5 处）**：改完跑三件套＋引号配平＋写该节账，交用户看一眼，确认了再铺。
- **逐节铺开时一节一停**：改前跑三件套留底 → 改 → 改后三件套＋配平 → 记账。别一口气全改完（中途能叫停才敢往前铺）。
- **每节账**用这张表：

| 条 | 改前位置（原文串） | 改法 | 结果 |
|:--|:--|:--|:--|

账行另附：本文字数增减、行数增减、量尺关键项、扫雷结果、配平数、同步核结果。

- **改法与预审结论不一致就写出来**（例：原计划「整行改成动作」，实际只删了复述尾——因为整行删掉会让下一行的「那一个钟头」失去指代）。
- **成对话语一起改**：改一句台词前先看紧邻的问答／称呼／复述——只改半截会让后一句失去指针对（实测：把「今天光走得早。」改成「今天的光没了。」之后，下一句「早吗？」就对不上，必须一并改成「没了？」）。
- **「删掉整段」的建议要过波及检查**：某一视角为提速开的大砍（例：删掉 27 行导览），若会连带删掉别路独立评为「全篇最稳」的那一句，**不采整段、只做最小减法**——跨路命中的最优句优先于单一视角的提速诉求。
- **定位**：落笔前 `grep -c -- '<改前原文串>'` 断言**全篇唯一**（≥2 就补上下文重取）；改完核旧串消失、新串在位。**不用行号定位**。
- **快照＝改前那次提交**（`git show <sha>:<file>`），别另建快照目录。

## 四、同步副本（正文多篇＋一份工作稿）

每条改动同时落所有副本；改完靠脚本判，不信任手工：

```python
body = lambda p: [l for l in open(p, encoding='utf-8').read().split('\n')
                 if l.strip() and not l.startswith('# ') and l.strip() != '---']
assert body('上篇.md') + body('下篇.md') == body('工作稿.md')   # 拼接逐行相等
```

## 五、验收七道（每节同尺，全篇再核一遍）

1. 该节条目 **100% 闭合**，或写明「不落 ＋ 理由」（说了没做＝事故）
2. 量尺不劣化（不越线、不出新 ⚠️）
3. 扫雷仍全过
4. 引号配平不变（删行、拆行都不许破坏）
5. 机械项清零（`，……` 连用／内引号混用）＋**归属清楚**（两人同段该补的归属语在位；**拆行不是解法**，段＝一拍）
6. 同步副本**拼接逐行相等**
7. 发布格式闸门（会被 Markdown 渲染的稿子：分隔线上下各留空行）

**止损**：改完一节先点检，出新 ⚠️ 或扫雷报警就当场核因，别带着问题往下走。

## 六、与「待拍」并行

条目分两堆：**可直接改的**当场落，**定调级／结构级（方向选择、身份落差、大段删并）**不动、等用户拍；两者同节时先落前者，二刀时用改前提交做比对。用户分档点头（先格式口径 → 再节级结构 → 最后定调）时，别把三档混成一次请求。

## §七 评审产出怎么落地成修订 · 逐条判据（2026-09-22 从 SKILL.md 并入）


核过引文、分完层，才轮到改稿。用户定的顺位是：**先分发、再逐个改、先做计划**——照这个走，别自己改成「边读边改」。

- **先分发到剧情点**：把条目合表去重，**逐条挂到章节／节上**（节 → 行范围 → 病 → 改法），落一份分发表；**没有分发表就别动笔**（按「来源」排会漏节，按「节」排才知道哪节要一口气改五处）。
- **先做一个小样**（一节 2–5 处）＋三件套＋该节账，交用户看一眼再铺——用户的验收习惯就是**先拿一件小样确认，再谈批量**。之后**一节一停、一节一账**。
- **分层并行**：能直接改的先落；**定调级／结构级（方向选择、身份落差、大段删并）不动**，等用户拍第二刀——两者同节时先落前者，靠改前提交做比对。「说了没做」和「自作主张改了待拍项」同样严重。
- **用户说「按计划逐个批改」时判据不变**：把待拍清单**逐条给一个裁决**（落／不落＋理由），能小改的照落；三类**仍不代拍**——① 定调级（作品定位，改稿解决不了）② 大砍（整段删并，属大改）③ 加内容（加事件／加解释，前者要过「这一场本来就该发生吗」那一问，后者可能撞「不解释」红线）。不落的要落到档里，并给出「等你一句话」的那一句问；用户没拍的档不要混在一次请求里。
- **定位与快照**：用**改前原文串**定位（行号会飘），落笔前 `grep -c` 断言全篇唯一；快照就靠**改前那次提交**，不另建快照目录。多副本（正文几篇＋工作稿）同步与「拼接逐行相等」核法见 §四。
- **别自己打自己**：并段（段＝一拍）治的是「一句一行」，但**拆行也不是解法**——用户口径（原话）：「对话形式需要确保避免这件事：**一句就是一行，无论这句话的长短，都同理**」。实测按「一行一说话人」拆了 4 处，被整体打回、整条撤回：**两人同段只要归属清楚就原样留着；归属不清就补归属语（「X 说／X 问」），不拆段落**。先 `grep` 出「一行含 ≥2 段台词」的行，逐行判是「同一人被一拍叙述隔开」（体例，保留）还是「归属真缺」（补归属语）。
- **发布格式闸门**：会被 Markdown 渲染的稿子，分隔线 `---` **上下各留一个空行**（紧贴正文时上一行被渲染成二级标题）；改完源再重跑生成器出成品稿。
- **删大段前先查「正面判定」**：小队最干脆的一条常是「这段删掉」（实测「该删 500 字就从这儿出」）——落刀前先过一遍该段里有没有前轮判过「**写对了／最稳**」的句子；撞上正面判定就是错杀，改成只删重复的那一句。
- **删台词行会改引号计数**：删／拆分台词后重核「」配平，**差值应等于删掉的对数**——对不上就是漏删或删错（跟配对不看总数看差额）。
- **开工前先把「变动单＋上轮不确定清单」清点成三条路**：逐条判**已覆盖／要补／要拍**。**「要补」里凡自己能做的（改账、口径回填、能自己判的局部修正）先补完再动笔**；**「要拍」的当场缩成一条窄问题**（带证据＋推荐值＋「不拍也能先弄别的」），**别把十条口径一起递上去**——用户说「没有别的就动手」时，回一个十条的清单等于把活又还给他。
- **整版被驳回时先回滚，再谈改**：用户驳回**整个**交回的版本（不是逐条打回）＝这一版不能当基线——`git checkout <上一个干净提交> -- <该单元>/正文.md` 退回去，再把病因与「该单元的上限」写成提案待拍；**别在错稿上继续改，也别立刻再交一版**（连交两版＝第二次被打回）。驳回的病因多半是「把下游的『第一次』提前用掉了」这一类**归属错**，不是句子层的问题——先看下游那一份自己写着的口径（它常写出「在这儿……在那边……」这种对照句，那就是它在等下上游交出来）。
- **撤／移一拍之前先读下游有没有「接班人」**：想把一节里的某拍（一句台词／一次点名／一个动作）撤掉时，先翻下游那一节——它往往已经有一句在位的、更好的说法，**撤了上游就等于把落点让给了它，一个字都不用搬**（实测：撤掉上游「你有翅膀了」整组命名，下游一句「张开了。」（紧跟「它没停」之后、不解释它是什么）接得比原文值钱）。**撤完还要查「那个词还剩几处」**——撤命名就确认那个名词在该角色台词里**归零**，别一半撤一半留。同类方向相反的是「加戏之前先校梯度」（见任务书那一节）。
- **撤完要回读断口**：一句台词往往带着**两端**——它的**引出语**（「他问了一声」「他把话递过来」）与**应答应**（「她没接这句」）。撤台词时只删引号里那串，会留下**半句悬着的引出语**（实测留下「他那头问了一声，」而后面再无话），读起来像漏字，且量尺扫雷全不报。**撤完固定回读它前后各一段**，把引出语／应答应一并收拾：或改成不指向具体话的说法（「没接这句」），或整句撤。同理，改一句台词的**内容**也要看它的应答应还对不对。
- **并段 ≠ 把两句台词并排**：并段允许「连续短问答并成一段」（≤3 句台词），但**挨着的两句之间要有动作夹层或归属**；两句光秃秃对贴＝退化成剧本（用户口径：那叫「合并行退步」）。审稿时拿它当标准：**把 `」\s*「` 全量列出来逐处看中间那一笔在不在**——量尺只算「纯台词段」，看不见这个。
- **定调级问题不一定靠改稿解决**：作品定位／身份落差这类，先问一句「能不能用**发布端**交代」——发布稿的说明块（`--note` 整块替换）能写定位句，**正文 0 字改动**；比在正文里加解释便宜得多。
